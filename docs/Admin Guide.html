⚙️ 던킨 매장 대장님 설명서

직원들 시간을 관리하고 월급을 주는 방법!

🌐 인터넷 주소 (접속하세요!)
관리자용: 여기 클릭
직원용: 여기 클릭

1. 📝 직원 등록하기 (새 친구 맞이)

1
[직원 관리] 메뉴로 갑니다.
2
새 직원의 이름, 전화번호, 시급(1시간에 얼마 줄지)을 입력합니다.
3
직원이 로그인할 수 있게 아이디와 비밀번호를 알려줍니다.

2. 📅 근무표 짜기 (언제 일할까?)

1
[스케줄] 메뉴에서 달력을 봅니다.
2
일할 날짜를 누르고 누가, 몇 시부터 몇 시까지 일할지 정합니다.
3
저장을 누르면 모든 직원이 포스기에서 확인할 수 있어요!

3. ✅ 출퇴근 확인 및 승인 (맞게 일했나?)

직원이 버튼을 누르면 관리자님께 '확인해 주세요!'라는 요청이 옵니다.

1
[근태/출퇴근] 메뉴에서 주황색(대기중) 기록을 찾습니다.
2
[승인] 버튼: "맞게 일했네! 돈 줘도 돼." $\rightarrow$ 월급에 포함됨
3
[거절] 버튼: "이 기록은 잘못됐어. 인정 못 해!" $\rightarrow$ 월급에서 빠짐

4. 💰 월급 계산 및 명세서 (돈 주기)

1
[정산] 메뉴에서 이번 달을 선택합니다.
2
컴퓨터가 자동으로 기본 월급 + 추가 근무 수당을 계산해서 합계를 보여줍니다.
3
금액이 맞다면 [정산 완료]를 누르고, 임금 명세서(월급 표)를 출력해서 직원에게 줍니다.
🚨 꼭 기억하세요!
직원이 퇴근 버튼을 안 눌러서 기록이 뻥 뚫려 있다면, 관리자님이 직접 [수정] 버튼을 눌러 시간을 맞춰주신 뒤 '승인'을 눌러야 월급이 나갑니다!
