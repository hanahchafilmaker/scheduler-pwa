🔐 로그인 방법

관리자 계정으로 접속하여 모든 권한을 사용하세요.

제공된 관리자 URL 접속 후 ID/PW를 입력하면 즉시 메인 대시보드로 연결됩니다.

📊 근태 현황 (Attendance Tab)

실시간 근무 상태를 확인하고 잘못된 기록을 바로잡는 곳입니다.

실시간 모니터링현재 근무 중(WORKING)인 직원과 퇴근(CLOSED)한 직원을 구분합니다.
정확한 시간 확인초 단위까지 기록된 출퇴근 시간을 확인하여 정산 기준을 잡습니다.
즉시 보정퇴근 버튼을 누르지 않은 직원의 시간을 [수정] 버튼으로 직접 맞춰줍니다.
대타 확인원래 누가 오기로 했고, 실제로 누가 왔는지 비교합니다.

📅 근무 계획 (Schedule Tab)

미래의 근무 표를 짭니다. 이 계획은 정산의 기준점이 됩니다.

스케줄 배정날짜, 시간, 파트별로 직원을 배치합니다.
계획 수정시간 변경 시 즉시 수정하여 직원이 포스기에서 확인하게 합니다.

👥 직원 관리 (Employee Tab)

기본 정보 등록이름, 연락처와 함께 정산의 기준이 될 이메일 주소를 정확히 입력합니다.
시급 설정직원별로 다른 시급을 설정하여 자동 계산이 가능하게 합니다.

✅ 승인 처리 (Approval Tab)

핵심 룰: "관리자가 [승인]하지 않은 추가 근무는 임금으로 지급하지 않습니다."
승인 대상스케줄 외 출근, 대타 근무, 연장 근무 기록이 이곳에 모입니다.
검토 및 결정실제 근무가 확인되면 [승인], 인정 불가하면 [거절] 처리합니다.

💰 급여 정산 (Settlement Tab)

가장 엄격하게 계산되는 최종 단계입니다.

항목계산 규칙결과

조기출근계획보다 일찍 와서 버튼 누르면?최대 5분까지만 인정

퇴근 누락퇴근 버튼을 안 누르고 간 경우?연장근무 인정 불가
