근태 기록 및 임금 산정 지침

Dunkin POS Attendance Standard Operating Procedure

01. 시스템 접속 절차
01 포스기 메인 화면의 [스케줄러] 아이콘을 실행합니다.
02 본인에게 부여된 비밀번호 4자리를 입력합니다. (아이디 입력 없음)
03 로그인 완료 후 즉시 본인의 근무 상태를 확인합니다.
02. 출퇴근 기록 의무

모든 임금은 스케줄표가 아닌 실제 버튼 클릭 시간을 기준으로 산정됩니다.

출근 시 🟢 [출근] 버튼 클릭
퇴근 시 🔴 [퇴근] 버튼 클릭
03. 임금 산정 및 공제 규칙
구분 기준 및 처리 결과
지각 계획 시간보다 1분이라도 늦을 시, 늦은 분만큼 전액 공제
조기 출근 계획 시간 전 출근 시, 최대 5분까지만 근무 시간 인정
추가 근무 기록은 자동 생성되나, 관리자 승인 후에만 임금 지급
04. 미이행 시 패널티
[퇴근 버튼 누락 시 주의사항]
퇴근 버튼을 누르지 않고 귀가할 경우,
해당 일의 모든 연장 근무 수당은 인정되지 않습니다.
또한, 임금 정산이 지연되며 반복 시 근태 패널티가 부여됩니다.
05. 임금 명세서 확인
최종 정산 완료 후, 등록된 개인 이메일로
상세 임금 명세서(PDF)가 발송됩니다.
