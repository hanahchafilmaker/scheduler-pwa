# 출퇴근 운영 규칙

## 핵심 원칙

이 프로젝트의 기준은 다음과 같다.

- schedule = 계획
- attendance = 실제 기록

정산은 반드시 attendance 기준으로 계산한다.

## 정산 기준

정산에 반영되는 기록은 다음 조건을 모두 만족해야 한다.

- check_in 있음
- check_out 있음
- approved = true

승인되지 않은 기록은 정산에 포함하지 않는다.

## 출근 처리

직원은 본인의 근무 시작 시간에 맞춰 출근한다.

예외 상황은 다음과 같다.

- 스케줄 외 출근
- 시간외 출근
- 대타 출근

이 경우 관리자 승인 대기로 분류한다.

## 퇴근 처리

직원이 퇴근 버튼을 누르면 check_out이 기록된다.

퇴근 기록이 없는 경우 자동퇴근 규칙을 적용할 수 있다.

## 미출근 처리

오늘 schedule 기준으로 attendance 기록이 없으면 미출근 또는 예정으로 분류한다.

- 출근 시간 전: 예정
- 출근 시간 경과 후: 미출근

## 주의사항

schedule은 계획 데이터이므로 실제 정산에 직접 사용하지 않는다.
attendance가 실제 근무 기록의 기준이다.
