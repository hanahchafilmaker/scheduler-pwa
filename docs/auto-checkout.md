# 자동퇴근 규칙

## 목적

직원이 퇴근 버튼을 누르지 않았을 때,
운영자가 누락 기록을 쉽게 확인하고 보정하기 위한 규칙이다.

## 기본 원칙

자동퇴근은 실제 퇴근 기록을 대체하기 위한 보조 규칙이다.

직원이 직접 퇴근 버튼을 누르는 것이 우선이다.

## 자동퇴근 예정 조건

다음 조건을 만족하면 자동퇴근 예정으로 분류한다.

- check_in 있음
- check_out 없음
- planned_end 기준 시간이 지남
- AUTO_CHECKOUT_GRACE_MIN 유예 시간에 가까워짐 또는 경과

## 유예 시간

현재 기본 유예 시간:

AUTO_CHECKOUT_GRACE_MIN = 30

## 예시

마감 근무가 22:00 종료이고 유예 시간이 30분이면:

- 22:00 이전: 근무중
- 22:00 이후: 퇴근 확인 필요
- 22:30 이후: 자동퇴근 처리 대상

## 주의사항

자동퇴근은 attendance 기준으로 처리한다.

schedule은 planned_end 확인용으로만 사용한다.
