🔐 로그인 방법

사용자 권한에 따라 로그인 환경이 다릅니다.

직원 POS 단말기: 포스기에 이미 설치된 스케줄러 아이콘을 클릭하여 접속 후, 부여받은 계정으로 로그인합니다.
관리자 원격 접속: PC 또는 모바일에서 아래 주소로 접속하여 관리자 계정으로 로그인합니다.
https://dunkin-admin.vercel.app/
💡 공통: 로그인 정보(ID/PW)를 잊으신 경우, 매장 관리자에게 문의하시기 바랍니다.

🖥️ 포스기 사용법 Staff

직원분들은 포스기 화면에서 본인의 스케줄을 확인하고 관리합니다.

1
내 스케줄 확인: 로그인 후 메인 화면에 표시되는 캘린더 또는 리스트를 통해 이번 주/이번 달 근무 시간을 즉시 확인합니다.
2
근무 요청 및 변경: 갑작스러운 일정 변경이 필요한 경우, 포스기 화면의 [요청] 버튼을 통해 관리자에게 변경 신청을 보냅니다.
3
상태 업데이트: 출근 후 또는 업무 종료 후, 본인의 상태를 업데이트하여 관리자가 실시간으로 확인할 수 있도록 합니다.
⚠️ 주의: 포스기에서 신청한 변경 사항은 관리자가 '승인' 버튼을 눌러야 최종 확정됩니다. 확정 여부를 반드시 다시 확인하세요.

⚙️ 관리자 사용법 Admin

관리자는 외부에서 웹/앱을 통해 매장 전체 인원을 통합 관리합니다.

1
인력 배치: 관리자 전용 페이지에서 날짜별/시간대별로 필요한 인원을 배치하고 전체 스케줄표를 작성합니다.
2
요청 처리: 직원이 포스기에서 보낸 스케줄 변경 요청 알림을 확인하고, 상황에 따라 [승인] 또는 [거절] 처리합니다.
3
계정 관리: 신입 직원 등록 및 기존 직원의 정보 수정, 권한 설정을 수행합니다.
4
데이터 확인: 전체 근무 시간 통계를 통해 인건비 및 인력 운영 효율성을 분석합니다.

❓ 자주 묻는 질문 (FAQ)

포스기 화면이 멈췄거나 접속이 안 돼요.

브라우저를 완전히 종료했다가 다시 실행하거나, 포스기의 네트워크 연결 상태를 확인해 주세요.

스케줄을 변경했는데 반영이 안 됐어요.

직원이 신청한 내용은 관리자가 '승인'을 완료해야만 캘린더에 반영됩니다. 관리자에게 승인 여부를 문의하세요.

관리자 페이지는 폰으로도 볼 수 있나요?

네, 제공된 URL을 통해 스마트폰 브라우저로 접속하시면 언제 어디서든 스케줄 관리가 가능합니다.
